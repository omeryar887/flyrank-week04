# Known Limitations

1. The MVP is read-only. It cannot update notes or project files automatically.
2. It uses a local MCP server, so the machine must be running and the client must be configured correctly.
3. The agent can still make incorrect interpretations of retrieved text; human review remains required.
4. The current server searches plain UTF-8 text files. It is not a PDF parser or general web search engine.
5. The exact two-minute recording and actual run timing must be produced by the user during the live run.

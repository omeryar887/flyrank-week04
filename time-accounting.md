# Time Accounting

## Method
Compare the time required to create useful notes manually with the time required when using the workflow. Record setup separately instead of hiding it.

## Initial setup cost
Estimated one-time setup for the no-code workflow:

| Task | Estimated time |
|---|---:|
| Choose pipeline and define stages | 45 min |
| Write project instructions | 60 min |
| Write and refine four prompts | 75 min |
| Define handoffs and output format | 45 min |
| Prepare five test inputs | 30 min |
| Initial testing/troubleshooting | 60 min |
| Evidence/documentation | 45 min |
| **Total setup** | **6 hours 20 min** |

These are planning/build estimates, not a claim that an external tool automatically took exactly this amount of time.

## Honest interpretation
The workflow should not be called a time saver simply because the AI generates text quickly. Setup, source preparation, waiting time, reruns, correction, and human verification all count.

The first few runs may save little or even cost more time because the workflow is still being tested. The useful comparison is the repeatable cost after setup.

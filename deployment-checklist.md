# Week 4 — Deployment Checklist

## Netlify

1. Create a Netlify account.
2. Open the Netlify deploy/drop area.
3. Upload the `stack-and-empty-live` folder.
4. Make sure `index.html` is directly inside the uploaded folder.
5. Wait for the deployment to finish.
6. Open the generated public URL.

## Verify

- [ ] URL opens on laptop
- [ ] URL opens on phone
- [ ] Name appears correctly
- [ ] Page is readable on mobile
- [ ] No broken CSS
- [ ] Screenshot captured

## Evidence

After the deployment is real, add the phone screenshot to the Week 4 evidence folder.

# FL-07 Evaluation Checklist

- [ ] Core job works end to end on a brand-new input.
- [ ] At least one real MCP/file/data connection is used.
- [ ] The build follows the FL-06 direction or documents deviations.
- [ ] Build log contains actual iteration, not only a polished retrospective.
- [ ] Raw, unedited approximately 2-minute capture shows the complete loop.
- [ ] No manual edits occur between agent steps.
- [ ] Tool use is visible in the evidence.
- [ ] Final output identifies source evidence and uncertainty.

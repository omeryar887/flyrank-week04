# Evidence Checklist

## Required by the assignment

- [x] Working workflow design.
- [x] Step diagram.
- [x] Three or more distinct steps.
- [x] Every prompt/configuration documented.
- [x] Defined handoffs.
- [x] Five test inputs documented.
- [x] Time-saving measurement method.
- [x] Failure points.
- [x] Human review requirements.

## Evidence that must be captured during actual external execution

- [ ] Screenshot of the configured Claude Project or selected no-code tool.
- [ ] Screenshot showing a complete end-to-end run.
- [ ] Actual output for each of the five runs.
- [ ] Start/end timestamps or stopwatch times for manual and workflow comparisons.
- [ ] Final five-run results copied into the run files.
- [ ] Working project/share URL if the tool provides one.

## Honesty rule
Do not add fake screenshots, fake URLs, fake timings, or invented outputs. Replace the marked evidence sections with actual results after running the workflow.
